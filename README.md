1. 电商行业是什么
2. 目前电商行业的实际情况
3. 普通人是否能低成本进入电商
4. 电商创业如何短平快试错
5. 如何建立自己的创业 SOP
6. 如何快速找寻市场机会和信息

## 在线演示

https://8888vip.github.io/ai-commerce-field-workshop/

## 使用方式

- 浏览器打开在线地址即可演示。
- 方向键切换页面，`Home`/`End` 跳转首尾，`Esc` 打开总览，`B` 切换静态模式，`F` 进入全屏。
- 页面为纯静态资源，下载仓库后直接打开 `index.html` 也可离线使用。
